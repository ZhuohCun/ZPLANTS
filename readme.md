* 「ZPLANTS」-- An AI-Based Plant Recognition \& Management Platform
* This is a campus plant recognition \& management system, originally developed for YNU to manage campus plants
* 1\. config frontend \& backend
* 2\. initialize database (run backend\\database\\schema\_mysql.sql and then backend\\database\\seed\_mysql.sql)
* 3\. run redis server (redis\\redis-server.exe)
* 4\. run backend (backend\\app.py)
* 5\. run model service (model\_service\\application\_layer\\model\_service.py)
* 6\. go to the frontend folder and run "pnpm install", and the start the frontend by entering "npm run dev"
* 7\. enjoy
